# 需求

用户是查制度/产品信息的员工。输入 question 与可选 history（role/content 列表）；合成文档包含 ID、版本日期、主题、标题、正文。输出回答、逐字引用、资料缺口和任务状态。

范围限报销与字幕功能的合成资料，不对外部事实作答。成功标准：单一制度给出原文支持的答案；30/15 天冲突同时引用并请求适用范围与优先级，日期新不等于优先；改写与上下文追问能找到相同主题；故障/无资料不编造；替换文档后答案同步改变。

必须场景及证据映射见评估文档。最大 12 次决策/工具动作，耗尽返回 incomplete/limit_reached，模型错误返回 incomplete/model_error。
