# 设计与取舍

输入校验 → 模型选择 search_documents(query) → 执行并返回候选元数据 → 模型选择 read_excerpt(doc_id) → 读取原文 → 模型补查、继续读、冲突澄清或 respond(disposition,doc_ids)。每次真实调用接收完整已执行历史及当前状态；无预设真实决策日志。

检索采用小型主题别名字典。工具返回同主题所有候选且标记不截断；读取必须先检索。回应前保护层要求相关候选全部读取且引用完整，防止隐藏冲突。日期仅作引用元数据，不提供优先级。历史仅帮助解析显式追问主题，历史中的事实不当作证据。

选择抽取式答案：模型决定检索、阅读及回答类型，最终原文由工具生成，防止错误引用。不同原文保守视为冲突；这种方法会将等价表述或互补内容误报冲突，但不会擅自选一个版本。不是通用企业搜索引擎，也不是完整语义冲突判定器。

不采用框架，Python 标准库负责 HTTP/JSON/CLI，便于三小时核心范围内交付。模型选择错误时工具返回校验结果供下一轮调整；Mock 的固定策略仅供离线测试。
